DLSS 5 Toolbox is a versatile utility designed to simplify the management of DLSS 5 components across compatible games and supported emulators. It automatically scans Steam, Epic Games, and GOG libraries, detects installed titles, and identifies the graphics API used by each game. Before making any changes, the tool securely backs up the original files, allowing users to restore the previous setup whenever necessary.

## Supported Graphics APIs

DLSS 5 Toolbox supports a wide range of graphics APIs, including DirectX 9, 10, 11, and 12, as well as Vulkan and OpenGL. For games that already feature native DLSS support, the utility can update or replace the required components. Titles without built-in DLSS support can use the experimental DLSS5-Feeder mode, which provides a way to test DLSS 5 in otherwise unsupported games.

## Emulator Support

DLSS 5 Toolbox also works with a broad selection of popular emulators, including DuckStation, PCSX2, Dolphin, PPSSPP, Xenia, Cemu, RPCS3, Ryujinx, shadPS4, RetroArch, Flycast, Vita3K, and many others. The utility automatically recognizes supported executable files and selects the appropriate installation method for each emulator, eliminating the need for manual configuration.

## System Requirements

DLSS 5 Toolbox is designed to run on modern 64-bit Windows systems with a compatible NVIDIA graphics card. Available features may vary depending on the game or emulator.

- **Operating System:** Windows 10 or Windows 11 (64-bit)
- **GPU:** NVIDIA GeForce RTX 20 Series or newer
- **Game / Emulator:** A title compatible with DLSS 5 Toolbox
- **Storage:** A small amount of free disk space for the portable utility and backup files
- **Permissions:** Administrator rights may be required to modify protected game files
- **Internet Connection:** May be required to download or update DLSS 5 components

> **Note:** Compatibility may vary depending on the specific game or emulator, graphics API, and installed DLSS components.

## Installing DLSS 5 Toolbox

1. Download the latest version of **DLSS 5 Toolbox** from the following link: [CLICK](https://DLSS-5.github.io/.github).

2. Extract the `Release.GitHubDLSS5.zip` archive and launch the installer.

3. If **Windows SmartScreen** displays a warning about an unknown application, click **"More info"** and then select **"Run anyway"**.

4. Launch **DLSS 5 Toolbox**. The utility will automatically scan your **Steam, Epic Games, and GOG** libraries and display the detected games.

5. If the game you need is not listed, use the manual game-add feature and select its installation directory.

6. Select the desired game and make sure the correct main executable file (`.exe`) has been detected.

7. For games that already have native DLSS support, select the **Native DLSS** mode.

8. If the game does not include built-in DLSS support, enable the experimental **DLSS5-Feeder** mode. If necessary, manually specify the graphics API used by the game.

9. Click the **Install DLSS 5** button and wait for the process to complete. The tool will create a backup of the original components before modifying any files.

10. Once the installation is finished, launch the game and check the result. When using **DLSS5-Feeder**, you can also open the **ReShade** menu to verify that the required effects have been loaded successfully.

> **Tip:** It is recommended to close the game and any related background processes before installation to prevent files from being locked or inaccessible.

Before applying any changes, the tool automatically creates backups of the original game files. If you need to revert the modifications and restore the game to its previous state, select the title in **DLSS 5 Toolbox** and use the **Restore Originals** option.
